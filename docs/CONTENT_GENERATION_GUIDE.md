# Покроковий регламент та стандарт створення навчальних матеріалів (Німецька мова в контексті)

Цей документ є головною інструкцією (Blueprint) для штучного інтелекту (**Antigravity**, **Codex**, **ChatGPT**, **Claude** або іншої LLM) при генерації нових навчальних карток та речень для додатку вивчення німецької мови.

---

## 🎯 Головна філософія навчальних матеріалів

1. **Слова вивчаються лише в живих реченнях і в різних граматичних формах.** Одне слово — це мінімум 3 речення різних рівнів складності (`просте`, `середнє`, `складніше`), де слово виступає в різних формах (для іменників — різні відмінки та однина/множина; для дієслів — різні особи *Präsens* зі зміною кореневої голосної, *Präteritum*, *Perfekt*, інфінітивні конструкції).
2. **Золоте правило перехресних речень (Cross-Pollination / Метод $i+1$):**
   * **ОБОВ'ЯЗКОВО для всіх наступних LLM:** Коли ти генеруєш речення для цільового слова, **не вигадуй випадкові абстрактні речення**. Кожне речення має бути **перехресним** — тобто одночасно містити **від 2 до 4 інших слів із поточного списку користувача або з його повного словника** (`data/user_vocabulary_full.txt` та `python cli.py export-vocab`).
   * *Приклад перехресного речення:* якщо ми робимо картку для слова `die Soße` (соус), а в словнику користувача є слова `dunkel`, `sauber`, `das Kleid`, `verschütten` — складаємо речення: *"Ich habe aus Versehen die dunkle Soße auf mein sauberes Kleid verschüttet."* Так користувач під час прослуховування одного речення одночасно повторює 5 своїх слів у живому контексті!
   * Уникай складної побічної лексики, якої немає у словнику користувача, якщо її можна замінити словами з його списку.
3. **Глибокий інтерактивний розбір без зайвої «води»:**
   * Кожне ключове слово в реченні має спливаючу картку (тултіп) з морфологією та типовими конструкціями.
   * Кожне речення має блок **«Чому така складність і що помітити»** та розмітку **рамкової конструкції (`Satzklammer`)**.

## 📋 Покроковий алгоритм для ШІ-агента (6 кроків)

### Крок 1. Перевірка поточної бази слів користувача
Якщо ти працюєш локально у проєкті (через Antigravity або Codex CLI), перед генерацією виконай команду:
```bash
python cli.py export-vocab
```
Це виведе список уже відомих слів користувача. Використовуй їх як будівельний матеріал для нових речень!

### Крок 2. Категоризація та планування карток
Визнач режим запиту користувача:
* **Режим А: Список слів (`word_list`)** — наприклад, `Іменники · Ключі, дім` або мікс слів з уроку. Створи окрему картку (`card`) для кожного цільового слова, але переплети їх у спільних реченнях.
* **Режим Б: Граматична підтема (`grammar_topic`)** — наприклад:
  * *«Сильні та модальні дієслова (чергування голосних e → i / ie, a → ä)»*
  * *«Дієслова з керуванням Dativ (helfen, danken, gehören, gefallen, пасувати)»*
  * *«Дієслова з прийменниковим керуванням (warten auf + Akk, denken an + Akk, sich freuen auf/über)»*
  * *«Прийменники подвійного керування (Wechselpräpositionen: Wo? Dativ vs Wohin? Akkusativ)»*
  У цьому режимі кожна картка фокусується на конкретному дієслові або моделі керування, а 3 речення демонструють контраст форм (наприклад, *du gibst* vs *ihr gebt* vs *hat gegeben*, або *Wo? у Dativ* vs *Wohin? у Akkusativ*).

### Крок 3. Складання 3 рівнів речень для кожної картки
Для кожного слова обов'язково створи 3 речення:

| Рівень (`level`) | Мовний рівень | Що обов'язково має бути в реченні | Приклад (для `der Schlüssel`) |
| :--- | :--- | :--- | :--- |
| **`просте`** | A1 – A2 | Прямий або питальний порядок слів (4–7 слів). Слово в базовій формі (*Nominativ* або базова форма *Präsens*). | `Wo ist mein Schlüssel?` |
| **`середнє`** | A2 – B1 | Слово змінює форму: непрямий відмінок (*Akkusativ* або *Dativ*), множина, або часова рамка (*Perfekt* `haben/sein ... Partizip II`, *Präteritum*, модальне дієслово). Чітка **Satzklammer** (рамка речення). | `Ich habe meinen Schlüssel zu Hause vergessen.` |
| **`складніше`** | B1 – B2 | Складнопідрядне речення (`damit`, `weil`, `obwohl`, `wenn`, `dass`) або інфінітивний зворот (`um ... zu`), де дієслово йде в кінець; або поєднання `Dativ + Akkusativ` / фіксована конструкція. | `Kannst du mir deinen Schlüssel geben, damit ich die Tür öffnen kann?` |

### Крок 4. Розмітка токенів (`tokens`) у реченні
Кожне значуще слово (іменники, дієслова, модальні/допоміжні дієслова, важливі займенники чи сполучники) описується в масиві `tokens`:
* `word`: точний підрядок слова в реченні (наприклад, `"Schlüssel"`, `"geben"`, `"habe"`). Якщо слово зустрічається двічі, можна вказати `occurrence` (1 або 2).
* `pos`: тип підкреслення і кольору:
  * `"noun_m"` — іменник чол. роду (`der`, синій пунктир)
  * `"noun_f"` — іменник жін. роду (`die`, червоно-рожевий пунктир)
  * `"noun_n"` — іменник сер. роду (`das`, зелений пунктир)
  * `"noun_pl"` — множина (фіолетовий пунктир)
  * `"verb"` — повнозначне або модальне/допоміжне дієслово (бірюзово-смарагдовий пунктир)
  * `"conj"` / `"prep"` — важливий сполучник чи прийменник, що змінює граматику речення (бурштиновий пунктир)
* `context_role`: пояснення форми **саме в цьому реченні** (наприклад: `"Akkusativ · Однина (meinen Schlüssel) — прямий додаток від дієслова vergessen"`).
* `frame_id`: (опціонально) номер або назва синтаксичної рамки (`"perfekt_1"`, `"modal_1"`, `"nebensatz_1"`), щоб при наведенні у UI обидві частини конструкції (наприклад, `habe` ... `vergessen` або `Kannst` ... `geben`) підсвічувалися разом!
* `popup`: дані для темно-смарагдового спливаючого вікна (див. точну JSON-схему нижче).
  * **Важливо для сильних дієслів у `praesens`:** якщо в 2-й чи 3-й особі однини змінюється коренева голосна (наприклад, `geben` → `du gibst`, `fahren` → `du fährst`, `sehen` → `du siehst`), запиши змінену букву у квадратних дужках: `"du g[i]bst"`, `"du f[ä]hrst"`, `"du s[ie]hst"`. Інтерфейс автоматично підсвітить її жовтим маркером!

### Крок 5. Написання блоку «Чому така складність і що помітити» (`complexity_notes`)
У полі `complexity_notes` дай 2–3 короткі, конкретні пункти:
1. **Синтаксис / Порядок слів:** поясни рамку речення (*Satzklammer*) або чому дієслово опинилося в кінці після `damit / weil / dass`.
2. **Морфологія / Відмінки:** чому змінився артикль чи присвійний займенник (`mein` → `meinen` в *Akkusativ* чол. роду; `mir` в *Dativ* + `deinen Schlüssel` в *Akkusativ*).
3. **Лексичні нюанси:** сталі вирази (`zu Hause` vs `nach Hause`, `Bescheid geben`, `es gibt`).

### Крок 6. Імпорт та генерація озвучки (TTS)
Збережи згенерований JSON у папку `data/packs/<назва_пакету>.json` та запусти:
```bash
python cli.py import data/packs/<назва_пакету>.json --tts
```
Скрипт перевірить структуру, запише картки у SQLite і згенерує всі MP3-файли озвучки (німецькі нормальні, німецькі повільні та українські).

## 📋 Готовий шаблон промпту (для копіювання в Codex / ChatGPT / Claude)

Якщо ви генеруєте матеріали у зовнішній моделі, скористайтеся цим промптом (також він автоматично генерується у вкладці **«➕ AI Конструктор»** всередині додатку разом зі списком ваших уже вивчених слів):

```text
Ти — експертний викладач німецької мови та лінгвіст. Створи навчальний JSON-пакет для мого додатку вивчення німецької мови в контексті речень.

ВХІДНЕ ЗАВДАННЯ (Слова або граматична підтема):
{{USER_WORDS_OR_TOPIC}}

МІЙ АКТИВНИЙ СЛОВНИК (використовуй переважно ці слова + базову лексику A1-A2, щоб комбінувати їх у реченнях):
{{KNOWN_WORDS_LIST}}

ВИМОГИ ДО ГЕНЕРАЦІЇ:
1. Для кожного цільового слова створи картку з 3 реченнями різної складності: "просте" (A1-A2, базова форма), "середнє" (A2-B1, зміна відмінка/множини або Perfekt/Präteritum із рамковою конструкцією Satzklammer), "складніше" (B1-B2, підрядне речення з damit/weil/wenn/dass або керування Dativ + Akkusativ).
2. Намагайся в кожному реченні поєднувати одразу 2-3 слова зі списку або з мого активного словника.
3. У масиві `complexity_notes` дай 2-3 чіткі пояснення: чому такий порядок слів (Satzklammer), чому саме таке закінчення/відмінок і на які конструкції звернути увагу.
4. У масиві `tokens` розбери ключові іменники та дієслова речення:
   - Для іменників (`type: "noun"`): вкажи `singular_nom`, `plural_nom` та `context_case` (відмінок у цьому реченні). Колір `pos`: `"noun_m"` (der), `"noun_f"` (die), `"noun_n"` (das).
   - Для дієслів (`type: "verb"`): вкажи `infinitive`, `praesens` (2 особа однини `du ...`; якщо є чергування кореневої голосної e→i/ie або a→ä, візьми змінену літеру в квадратні дужки, напр. `"du g[i]bst"`), `praeteritum` (`du ...`), `perfekt` (`hat/ist ...`), `note` (пояснення чергування або Perfekt) та за потреби масив `constructions` (типові конструкції з відмінками, напр. `jemandem etwas geben · Dativ + Akkusativ`).
   - Якщо два слова утворюють рамку речення (напр. `habe ... vergessen` або `Kannst ... geben`), додай їм однаковий `frame_id` (напр. `"frame_1"`).
5. Поверни ВИКЛЮЧНО валідний JSON без зайвого тексту за схемою додатку.
```
