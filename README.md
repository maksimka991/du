# Deutsch im Kontext — Вивчення слів у реченнях та граматичних підтем

Локальний веб-додаток (Python FastAPI + SQLite + Edge-TTS) для вивчення німецьких слів у різних формах, граматичних підтем (сильні/модальні дієслова, керування відмінками) з інтерактивним розбором кожного речення та **фоновим режимом аудіо-подкасту** для прослуховування під час роботи за ПК.

## 🚀 Як запустити додаток

Потрібен Python 3.10 або новіший. Перед першим запуском виконайте `python -m pip install -r requirements.txt`.

1. Двічі клікніть на файл **`run.bat`** або запустіть у терміналі:
   ```bash
   python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --reload
   ```
2. Відкрийте у браузері: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

## 🧠 Як створювати нові навчальні матеріали (Напівавтоматичний режим)

Детальний покроковий план, методика $i+1$, вимоги до розбору та сувора JSON-схема описані у файлі:
👉 **[docs/CONTENT_GENERATION_GUIDE.md](docs/CONTENT_GENERATION_GUIDE.md)**

### Спосіб 1: Прямо в чаті Antigravity або Codex CLI
Просто напишіть у чат:
- *«Додай список слів: der Tisch, liegen, legen, stehen, stellen»*
- або *«Зроби граматичну підтему: Модальні дієслова в Präteritum та Perfekt»*

Агент автоматично:
1. Перевірить ваші вже вивчені слова (`python cli.py export-vocab`), щоб вплести їх у нові речення.
2. Створить JSON-пакет із 3 рівнями складності (`просте`, `середнє`, `складніше`), морфологічними тултіпами та розміткою рамки речення (`Satzklammer`).
3. Імпортує пакет і згенерує живі MP3-файли озвучки:
   ```bash
   python cli.py import data/packs/<назва_пакету>.json --tts
   ```

### Спосіб 2: Через вкладку «➕ AI Конструктор & Імпорт» у браузері
1. Відкрийте вкладку **«➕ AI Конструктор & Імпорт»**.
2. Введіть список слів або оберіть готовий шаблон граматичної підтеми.
3. Натисніть **«✨ Згенерувати покроковий промпт»** — додаток автоматично підставить ваш активний словник ($i+1$) та схему.
4. Скопіюйте промпт у будь-яку модель (Codex / ChatGPT / Claude), а отриманий JSON вставте у праву колонку. Натисніть **«Перевірити пакет»**, перегляньте кількість нових і змінених карток та підтвердьте імпорт.
5. Якщо озвучення не вдалося, картки вже збережені. Скористайтеся кнопкою генерації відсутнього аудіо для повторної спроби.

## 🛠 Корисні команди CLI (`cli.py`)

```bash
# Вивести список усіх відомих слів у базі (для генерації за методом i+1)
python cli.py export-vocab

# Вивести весь словник, включно з новими картками
python cli.py export-vocab --all

# Імпортувати JSON-пакет і одразу згенерувати MP3 озвучку (DE 1.0x, DE 0.8x, UKR)
python cli.py import data/packs/starter_pack.json --tts

# Перевірити пакет і побачити майбутні зміни
python cli.py import data/packs/starter_pack.json --preview

# Догенерувати відсутні аудіофайли для всіх речень у базі
python cli.py tts
```

## Повторити сьогодні

У вкладці **«Повторити сьогодні»** виберіть «Текст» або «Аудіо». Пригадайте переклад, відкрийте відповідь, перегляньте граматичний розбір і оцініть, наскільки добре згадали речення.

«Не згадав» повертає картку через 10 хвилин, «Важко» — через день, «Згадав» — через три дні. За наступних послідовних «Згадав» інтервал подвоюється до 30 днів. Прострочені картки з’являються перед новими. Історія зберігається в локальній базі навіть після повторного імпорту.

Генератор промптів використовує картки з двома послідовними успішними повтореннями як знайому лексику. Поки таких карток немає, він пропонує базову лексику A1–A2.

## Робочі дані та резервна копія

З версії 0.1.0 база й аудіо зберігаються в локальній теці `.du-data`, яку Git ігнорує. Для іншого розташування встановіть `DU_DATA_DIR`. Під час першого запуску застосунок копіює базу й аудіо з `data`, якщо робоча тека порожня. Якщо у вас є незакомічені зміни в старій базі, скопіюйте її разом із `data/audio` перед оновленням.

Щоб створити резервну копію, зупиніть сервер і CLI та скопіюйте всю робочу теку. Для відновлення зупиніть застосунок, перейменуйте поточну робочу теку й поверніть копію на її місце або вкажіть її шлях у `DU_DATA_DIR`.
