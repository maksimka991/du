# Генератор навчальних матеріалів з німецької мови

Коли користувач дає список слів (наприклад: *"додай слова: Haus, gehen, schnell..."*) або просить згенерувати речення за граматичною підтемою (наприклад: *"зроби підтему про сильні дієслова"* або *"дієслова з Dativ"*), виконай такі кроки:

## 1. Отримай поточний словник користувача та побудуй ПЕРЕХРЕСНІ речення ($i+1$)
1. Запусти команду в терміналі:
   ```bash
   python cli.py export-vocab
   ```
   А також переглянь повний архів слів користувача у файлі `data/user_vocabulary_full.txt`.
2. **КРИТИЧНЕ ПРАВИЛО ПЕРЕХРЕСНИХ РЕЧЕНЬ (Cross-Pollination):**
   - Бажано і обов'язково робити **перехресні речення** зі слів із словника користувача!
   - Кожне речення для цільового слова має включати **ще 2–4 слова** з нової порції слів або з `data/user_vocabulary_full.txt` / активної бази даних.
   - Усі ці використані супутні слова зі словника користувача також розмічай у масиві `tokens`, щоб користувач бачив їхні форми і міг клікнути на них у реченні.

## 2. Ознайомся зі стандартом та JSON-схемою
Прочитай файл `docs/CONTENT_GENERATION_GUIDE.md` — там описано сувору JSON-схему (`pack_title`, `category`, `pack_type`, `cards`, `sentences`, `complexity_notes`, `tokens`, `popup`).

Ключові вимоги:
- Для кожного слова — мінімум **3 речення**: `"просте"` (A1-A2), `"середнє"` (A2-B1, зміна відмінка/множини або Perfekt з рамкою речення), `"складніше"` (B1-B2, підрядне речення з `damit`, `weil`, `wenn`, `obwohl` або подвійне керування `Dativ + Akkusativ`).
- У дієслівних попапах (`type: "verb"`), якщо у формі `du ...` (Präsens) є зміна кореневої голосної (`e → i/ie`, `a → ä`), обов'язково виділи змінену голосну квадратними дужками, наприклад: `"du g[i]bst"`, `"du f[ä]hrst"`, `"du n[i]mmst"`.
- Для дієслів із важливим керуванням або сталими виразами заповни масив `constructions` (`pattern` + `meaning`) та `footer_summary`.
- Токенам, які утворюють синтаксичну рамку речення (*Satzklammer*, наприклад `habe ... vergessen` або `Kannst ... geben`), признач спільний `frame_id` (`"frame_1"`, `"frame_2"`).

## 3. Збережи JSON-пакет та запусти імпорт із синтезом мовлення
1. Запиши згенерований JSON у файл `data/packs/<slug_name>.json`.
2. Запусти команду імпорту та генерації MP3:
```bash
python cli.py import data/packs/<slug_name>.json --tts
```
3. Повідом користувача, які картки, форми слів та конструкції було додано до бази та озвучено.
